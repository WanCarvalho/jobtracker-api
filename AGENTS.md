# Formatação

- Entregue código formatado, com indentação, espaçamento e quebras de linha consistentes.
- No frontend, siga `frontend/.prettierrc` e execute `npm run format` em `frontend` após alterar TypeScript, HTML ou SCSS. Confira com `npm run format:check`.
- No backend, use quatro espaços para Java e execute `mvn spotless:apply` em `backend` após alterar fontes Java. Confira com `mvn spotless:check`.
- Mantenha a formatação separada de mudanças de comportamento e preserve as alterações existentes do usuário.
